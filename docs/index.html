⚙ Mise en place

1. Télécharger l'application

Télécharge ou clone le dépôt GitHub, puis double-clique sur :

  • Windows : lancer.bat
  • Mac / Linux : lancer.sh

Le navigateur s'ouvre automatiquement sur l'interface MJ.

2. Créer une campagne

Dans Créer & Gérer, crée ta campagne, ajoute tes personnages joueurs, tes PNJ et tes cartes.

3. Partager les fiches joueurs

Pour chaque personnage, définis un mot de passe et clique sur "Générer le lien". Envoie ce lien à ton joueur (par message, QR code, etc.). Il accédera à sa fiche depuis n'importe quel appareil, même entre les sessions — sans que le serveur tourne.

4. Lancer une session

Pendant la session, l'interface Jouer tourne sur ton ordinateur. Les joueurs se connectent via l'adresse IP affichée au démarrage.

💡 Les données de campagne restent sur ton ordinateur. GitHub Pages n'héberge que les outils statiques (cette page, les fiches, les dés, les références).

Rejoindre une session en cours

Ton MJ t'a communiqué une adresse IP (ex : 192.168.1.42:8000). Ouvre-la dans ton navigateur sur le même réseau Wi-Fi.

Consulter ta fiche hors-session

Ton MJ t'a envoyé un lien ? Ouvre-le ici (ou depuis ta boîte mail / tes messages), entre le mot de passe qu'il t'a donné, et ta fiche s'affiche. Mets la page en favori pour y revenir facilement.

🔒 Ta fiche est chiffrée dans l'URL — même nous ne pouvons pas la lire sans ton mot de passe.
